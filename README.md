# Vishal Nath Portfolio

Multi-page GitHub Pages portfolio.

## Structure

- `index.html` — homepage
- `about/` — about page
- `data/` — data & analytics page
- `projects/` — projects page
- `software/` — software page
- `experience/` — experience page
- `resume/` — resume page
- `assets/css/style.css` — shared design system
- `assets/js/theme.js` — shared dark/light mode

The pages are intentionally scaffolded first. Content and page-specific layouts can be developed one page at a time while preserving the shared visual system.
